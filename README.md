# Arnab Adhikari — Portfolio (New Design)

Modern, fully responsive personal portfolio.

## How to use

1. Open `index.html` in any browser (or use a local server).
2. Replace the placeholder images in the `images/` folder with real screenshots.

## Required Screenshots

Put these files inside the `images/` folder:

| File name              | Project                  |
|------------------------|--------------------------|
| profile.jpg            | Your profile photo       |
| aa-news.jpg            | A.A. News                |
| friendly-flux.jpg      | Friendly Flux / Math Class |
| beyonder-ai.jpg        | Beyonder AI 2.0          |
| money-manager.jpg      | My Money Manager         |
| portfolio.jpg          | This Portfolio           |
| weather-app.jpg        | My Weather App           |
| nebula-secret.jpg      | Nebula Secret            |
| file-organizer.jpg     | Nebula File Organizer    |
| qr-regen.jpg           | Nebula QR Re-generator   |
| satellite.jpg          | Satellite Tracker        |
| file-compressor.jpg    | Nebula File Compressor   |
| passportgrid.jpg       | Nebula Passportgrid      |

If an image is missing, a placeholder will be shown automatically.

## Structure

```
Arnab-Portfolio-New/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── projects.js
│   └── script.js
├── images/          ← put screenshots here
└── README.md
```

## Deploy

- GitHub Pages: push this folder and enable Pages from the `main` branch / root.
- Or any static host (Netlify, Vercel, etc.).
