## Overview

Modern, fully responsive personal portfolio of **Arnab Adhikari** — Student Developer focused on **Python, Flask & SQLite**.

This version merges the best of previous portfolio iterations:
- Beautiful animated hero with particle background & tech orbit
- Collaboration projects + Solo projects with rich cards
- Skills, About, Contact sections
- Full social presence (GitHub, LinkedIn, Facebook, Instagram, WhatsApp, Email)
- Smooth animations, preloader, scroll progress, back-to-top

---

## Features

- Clean & modern dark UI with cyan / mint accents
- Fully responsive (mobile + desktop)
- Preloader + scroll progress bar
- Particle background on hero
- Animated tech orbit around profile photo
- Project cards with team badges, feature lists & live demos
- Stats counters
- Contact cards for all major platforms
- Footer social links
